# phone ∧ shoot 説明書
スマートフォンを傾けて自機(キャラクター)を動かし、タップして撃つ、みんなで遊ぶシューティングゲームです。モニターに次々と現れる敵（バグ）を倒して、全3ステージの突破を目指します。

| 項目 | 内容 |
| --- | --- |
| 遊ぶ人数 | 同時に最大4人（ホストの設定で変更できます） |
| 遊ぶ機器 | モニター（PC）と、参加者それぞれのスマートフォン |
| ゲームの流れ | 全3ステージ。制限時間内に目標スコアへ届けばクリア、届かなければ TIME UP |
| クリア方法 | 全員で協力してステージを突破し、最後に個人のスコアで順位がつく |

## 参加方法

1. モニター（PC）でホスト画面を開く。左上にQRコードとルームID が表示される。
2. スマートフォンのカメラでQRコードを読み取り、表示されたページを開く（iPhone は Safari で開く）。
3. 必要なら名前（最大12文字）とキャラクターを選ぶ。選ばなければ自動で決まる。
4. JOIN を押す。センサーの使用を尋ねられたら「許可」を選ぶ。
5. 参加者がそろったら、カウントダウン（10秒）の後にゲームが始まる。参加者が増えるとカウントダウンは10秒に戻る。

| 画面 | URL | 備考 |
| --- | --- | --- |
| ホスト（ゲーム画面） | https://osu-denken.net/phone-and-shoot/host/ | モニターに接続してゲームのホストをするPC |
| コントローラー (プレイ画面) | QRコードから開く（https://osu-denken.net/phone-and-shoot/client/） | スマートフォンで参加する |
| ゲーム画面＋プレイ画面 | https://osu-denken.net/phone-and-shoot/play/ | PCでホストしながらキーボードで遊ぶ |

## 操作方法

### スマートフォン（プレイ画面）

| 操作 | 動き |
| --- | --- |
| スマートフォンを左右に傾ける | 自機が左右に動く（大きく傾けるほど速い） |
| SHOOT ボタンをタップ | 弾を撃つ。押し続けると連射する |
| アイテムのアイコンをタップ | 持っているアイテムを使う |
| 傾きリセット | 今の持ち方を「まっすぐ」として覚え直す |
| 右上のボタン | 全画面表示にする |

傾きは、JOIN した後の最初の持ち方を基準にします。持ち方が変わって動きがずれたら、傾きリセットを押してください。

### PCのキーボード（ゲーム画面＋プレイ画面）

| キー | 動き |
| --- | --- |
| `A` / `←` | 左へ動く |
| `D` / `→` | 右へ動く |
| `Shift` を押しながら移動 | 1.5倍の速さで動く |
| `Space` | 弾を撃つ（押し続けると連射） |
| `E` / `Enter` | 持っているアイテムを使う |

## ステージとルール

| ステージ | 目標スコア | 制限時間 | 敵の同時出現数 | 敵の出現間隔 | 大型の敵が出る間隔 | 敵の攻撃 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 100 | 120秒 | 6 | 1.0秒 | 6体に1体 | なし |
| 2 | 150 | 150秒 | 8 | 0.8秒 | 7体に1体 | なし |
| 3 | 200 | 200秒 | 7 | 1.2秒 | 4体に1体 | 弾を撃ってくる |

- 目標スコアはみんなの合計です。届いた時点でステージクリアとなり、次のステージへ進みます。
- 制限時間内に届かないと TIME UP（GAME OVER）になり、しばらくするとタイトルに戻ります。
- ステージ3の最後までクリアすると、結果が表示されます。
- プレイヤーが全員いなくなると、タイトルに戻ります。

### 難易度
タイトル画面で、ノーマルかハードを選びます。

| 項目 | ノーマル | ハード |
| --- | --- | --- |
| 敵の体力 | 通常 | 1.75倍 |
| 敵の速さ | 通常 | 1.25倍 |
| 敵に当たったときのダメージ | 1 | 2 |
| 倒れたとき | 10秒後に体力が全回復して復活 | ゲームから外れる |

### 体力とスコア
| 項目 | 内容 |
| --- | --- |
| 体力 | 初期値は5。敵や敵の弾に当たると減り、0になると倒れる |
| 弾 | 連続して撃てる間隔は0.25秒。画面に出せるのは1人あたり12発まで |
| スコア | 通常の敵を倒すと1点、大型の敵を倒すと2点 |
| タイムボーナス | ステージをクリアしたとき、残り時間1秒につき0.5点を、参加している全員に加算する |
| 結果 | 最終クリアと TIME UP のとき、全員のスコアが順位つきで表示される |

## 敵
| 敵 | 体力 | 倒したときのスコア | 特徴 |
| --- | --- | --- | --- |
| 通常の敵 | 1 | 1点 | 上から降りてくる。触れるとダメージを受ける |
| 大型の敵 | 3 | 2点 | 倒すとアイテムを落とす（画面にアイテムが5個あるときは落とさない） |

ステージ3の敵は、一番下の列を除いて、弾を撃ってきます。弾は、いちばん近い生存中のプレイヤーに向かって飛びます。

## 困ったとき
| 症状 | 対処 |
| --- | --- |
| JOIN を押しても参加できない | 会場のネットワークによっては、つながらないことがある。スマートフォンの Wi-Fi をオフにしてモバイル回線にするか、PC のテザリングにつなぐ。URL の末尾に `?debug=1` を付けると、画面の左下に接続状況が出る |
| 「満員のため参加できません」と出る | 参加人数の上限に達している。ホストが `?maxPlayers=` で上限を変えられる |
| 自機が勝手に動く、動かない | 傾きリセットを押す |
| iPhone でセンサーが使えない | ページを再読み込みして、もう一度 JOIN を押し、センサーの使用を「許可」する |
| 画面が止まった、タイトルに戻った | プレイヤーが全員いなくなると、タイトルに戻る。もう一度 QRコードから参加する |

URL のパラメータ（`debug`、`maxPlayers`、`seed`）の詳細は、[README](../README.md) を参照してください。
